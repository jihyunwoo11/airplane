# AIRLINER 여객기 백과사전

중학생을 위한 인터랙티브 여객기 백과사전입니다.

- 3D 여객기 모델(Three.js), 여객기 14기 도감, 실제 비율 크기 비교
- 비행 물리 시뮬레이터(양력·중력·추력·항력, 실속), 기체 구조 해부도
- 비행 단계 고도 그래프, 항공 역사 타임라인, 조종사 자격 테스트(퀴즈)

`index.html`(또는 `항공기_백과사전.html`)을 브라우저로 열면 됩니다.

## 파일 구성
- `index.html`, `항공기_백과사전.html`: 완성된 단일 HTML (데이터 포함)
- `template_v2.html`: 화면 틀 (데이터를 넣기 전)
- `data/`: 기종 데이터(`planes_a.js`, `planes_b.js`)와 학습 데이터(`learn.js`)

제원은 대표 모델 기준의 대략적인 값입니다.
